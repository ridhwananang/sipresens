# Image Assets – Login Page

Letakkan 2 file gambar berikut di folder ini (`public/images/`):

## 1. `school-icon.png`  ← **WAJIB**
Gambar 3D icon sekolah (globe + kubah biru Pelita Bangsa).
- Akan ditampilkan di sisi **kanan** halaman login.
- Gunakan format PNG dengan **background transparan** agar hasilnya bersih.
- Ukuran rekomendasi: minimal **600×600 px**.
- Path final: `public/images/school-icon.png`

## 2. `students-icon.png`  ← **WAJIB**
Ilustrasi kartun siswa-siswi (anak laki + perempuan seragam).
- Akan ditampilkan di sisi **kiri**, di samping teks "Welcome".
- Gunakan format PNG dengan **background transparan**.
- Ukuran rekomendasi: minimal **200×200 px**.
- Path final: `public/images/students-icon.png`

---
> Setelah meletakkan gambar, refresh browser – tidak perlu rebuild Vite
> karena file `public/` di-serve secara statis oleh Laravel.
